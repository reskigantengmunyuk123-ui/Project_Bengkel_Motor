Format:
- 18 file SVG vektor, ukuran 390 x 844 px. Bukan screenshot.
- MOTORTECH_Clickable_Prototype.html: prototype navigasi sederhana untuk melihat 18 layar berurutan.
- 19_Admin_Desktop_Prototype.html: prototype workspace admin desktop untuk dashboard, antrean, booking, pelanggan, layanan, sparepart, riwayat, laporan, antrean langsung, transaksi, dan pengaturan.
- motortech-logo.png: logo resmi untuk aset SVG serta prototype pada folder ini.
- Semua elemen gambar SVG dan teks dapat diimpor ke Figma untuk diedit.

Desktop admin:
- Buka 19_Admin_Desktop_Prototype.html di browser untuk melihat dan berpindah antar halaman admin versi layar lebar.
- Desain mobile 390 x 844 px tetap tersedia sebagai SVG terpisah; prototype desktop ini menunjukkan susunan navigasi samping, ringkasan, formulir, grafik, dan tabel yang memakai ruang desktop.

Cara impor ke Figma:
1. Ekstrak ZIP.
2. Di Figma, buat page baru bernama "MOTORTECH — Mobile".
3. Impor/drag setiap SVG ke canvas sesuai urutan 01–18.
4. Setiap SVG menjadi satu frame/objek desain. Jika perlu, gunakan Ungroup untuk mengedit elemen vektor.
5. Buat koneksi Prototype antar-frame sesuai alur di atas. SVG tidak membawa koneksi Prototype Figma secara otomatis.
6. Atur starting point pada 01_Beranda_Pelanggan dan 08_Login_Admin untuk alur pelanggan dan admin.

Catatan penting:
- Ini adalah rancangan lengkap 18 layar mobile-first berdasarkan daftar layar dan referensi visual yang terlihat pada screenshot.
- Data contoh (nama, nomor antrean, harga, jadwal) hanya placeholder desain, bukan data operasional nyata.
- HTML prototype menyediakan perpindahan layar Previous/Next dan daftar pilihan layar. Ini bukan backend atau aplikasi produksi.
- File Figma asli tidak dapat diedit langsung dari screenshot; untuk menyatukan ke file Figma Anda, impor aset ini ke dokumen yang sama.
